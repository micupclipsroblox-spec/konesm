Quick answers

FAQ

Helpful details for players and store visitors.

Is this the full Squarespace shop copied over?

Not yet. The supplied link is a Squarespace configuration URL, not a public product page, so this page uses clearly marked sample listings. Export your products as a CSV from Squarespace or share the public store URL and product images to rebuild the real catalogue.

Can I buy the sample products right now?

No. The cards are placeholders and don't accept payments. Connect them to your legitimate checkout and a secure system that delivers purchases in-game.

Does this website keep the Minecraft server online 24/7?

No. A static website cannot keep a Minecraft server running. Configure 24/7 uptime through your hosting provider's supported settings or use a host that offers always-on service.

Why might the link not work in Minecraft?

A web URL and a Minecraft server address are different things. Use the multiplayer hostname and port shown by the Minecraft server host, unless your Workers endpoint has been explicitly configured as a compatible proxy.

Can I put the admin password in this file?

No. Anything placed in public HTML or JavaScript can be read by visitors. Keep credentials private, rotate any password that has been shared, and use the host's secure admin login and documented controls.
